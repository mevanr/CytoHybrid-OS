
Transcriptomics-Informed Virtual Immune-Tissue Model
====================================================

This simulation implements a transcriptomics-informed virtual immune-tissue ABM.
Each virtual macrophage, T cell, NK cell, and Treg carries internal gene-program
scores, including NFkB_inflammatory, STAT3_IL6, IFNG_response,
cytotoxic_program, exhaustion_program, TGFB_regulatory, repair_program, and
migration_program.

Unlike a purely rule-based ABM in which RNA modules are only downstream readouts,
this model uses marker-gene/module programs upstream to regulate virtual-cell
functions: activation, cytokine secretion, suppression, cytotoxicity, motility,
proliferation, exhaustion, and repair.

Number of simulated tissues: 200
Regimes: acute_resolving, chronic, hyperinflammatory, immune_excluded, suppressed

Compared model arms:
1. Pure ML: pseudo-bulk marker modules
2. Pure ML: bulk + spatial marker modules
3. Mechanistic virtual-cell summaries
4. Hybrid: marker modules + spatial + virtual-cell MM

Interpretation:
The model tests whether marker-gene-informed virtual cell functions improve the
ability to decode inflammatory immune dynamics from transcriptomic data. Spatial
marker modules help distinguish immune exclusion, exhaustion, suppressive niches,
and unresolved damage that may be obscured in pseudo-bulk averages. The hybrid
model uses transcriptomic/spatial observations plus mechanistic virtual-cell
summaries to recover hidden parameters such as ECM/stromal barrier strength, NFkB gain,
TGF-beta/regulatory gain, exhaustion gain, cytotoxic gain, injury strength, and
repair capacity.
